Fortnite Remote — первая PWA-заготовка

Что работает:
- локальный таймер на 15 минут;
- ручное подтверждение после окончания;
- установка на главный экран iPhone после публикации по HTTPS.

Что НЕ работает:
- нет удалённого подключения к Windows;
- нет управления Fortnite и автоматического выхода/поиска матча;
- таймер работает, пока страница активна; iOS может приостанавливать фоновые вкладки.

Установка:
1. Разместить содержимое папки на HTTPS-хостинге (например, GitHub Pages).
2. Открыть опубликованный адрес в Safari на iPhone.
3. Нажать «Поделиться» → «На экран Домой» → «Добавить».

Не добавляйте в приложение пароли или PIN удалённого доступа.
